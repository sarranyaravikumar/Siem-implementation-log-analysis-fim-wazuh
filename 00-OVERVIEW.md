# 00 - Overview

## Project Overview

This project implements a Security Information and Event Management (SIEM) system using Wazuh with File Integrity Monitoring.

The Wazuh Manager is deployed on Ubuntu 22.04.5 LTS and a Windows endpoint is monitored using the Wazuh Agent.

## Objectives

- Implement Wazuh SIEM.
- Configure the Wazuh Manager.
- Connect a Windows Wazuh Agent.
- Monitor endpoint security events.
- Implement File Integrity Monitoring.
- Detect file creation, modification, and deletion.
- Analyze events through the Wazuh Dashboard.

## Prerequisites

- Ubuntu 22.04.5 LTS
- Windows endpoint
- Wazuh Agent
- Internet connection
- Oracle VirtualBox
- Basic Linux and Windows command-line knowledge

## Quick Start

1. Install Wazuh Manager on Ubuntu.
2. Access the Wazuh Dashboard.
3. Install the Wazuh Agent on Windows.
4. Register the agent with the manager.
5. Configure File Integrity Monitoring.
6. Perform file operations for testing.
7. Verify the generated events in the Wazuh Dashboard.

For detailed commands, refer to the project documentation PDF.
