# 01 - Concepts

## SIEM

Security Information and Event Management (SIEM) is a security solution used to collect, analyze, correlate, and monitor security events from different systems.

## Wazuh

Wazuh is an open-source security monitoring platform that provides capabilities such as:

- Security event monitoring
- Log analysis
- File Integrity Monitoring
- Vulnerability detection
- Security alerting

## Wazuh Manager

The Wazuh Manager is the central component responsible for receiving and analyzing events collected from Wazuh Agents.

## Wazuh Agent

The Wazuh Agent is installed on monitored endpoints. It collects relevant system and security information and sends it to the Wazuh Manager.

## File Integrity Monitoring

File Integrity Monitoring (FIM) monitors selected files and directories for changes.

It can detect:

- File creation
- File modification
- File deletion
- File integrity changes

## Wazuh Dashboard

The Wazuh Dashboard provides a graphical interface for viewing agents, security events, alerts, and monitoring information.
