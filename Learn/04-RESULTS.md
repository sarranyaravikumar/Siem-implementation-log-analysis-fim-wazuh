# 04 - Results

## Implementation Results

The project successfully achieved the following:

- Wazuh Manager deployed on Ubuntu.
- Windows Wazuh Agent installed successfully.
- Windows Agent connected with the Wazuh Manager.
- Security events collected from the Windows endpoint.
- File Integrity Monitoring configured.
- File creation detected.
- File modification detected.
- File deletion detected.
- Events visualized through the Wazuh Dashboard.

## FIM Verification

FIM was tested by performing file operations on the monitored Windows directory.

The generated events were observed through the Wazuh Dashboard.
